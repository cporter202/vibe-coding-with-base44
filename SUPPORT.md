# Support

## Help with this guide

Use this repository's issue templates for:

- Broken or outdated instructions
- Confusing explanations
- Broken links
- Ideas for new lessons or prompts

[Open a guide issue](https://github.com/cporter202/vibe-coding-with-base44/issues/new/choose).

## Help with Base44

Use Base44's official channels for:

- Account access
- Billing or subscriptions
- Private app details
- Platform outages
- Product bugs that need account-specific investigation

Start with [Base44 troubleshooting](https://docs.base44.com/Community-and-support/Troubleshooting), then use [Base44 Support](https://docs.base44.com/Community-and-support/Contacting-support) if needed.

## Before sharing a public reproduction

Remove:

- Passwords and API keys
- OAuth tokens
- Personal or customer data
- Private app URLs and account identifiers
- Payment information

Share the page, user role, exact steps, expected result, actual result, a redacted error, and the approximate time the problem occurred.
