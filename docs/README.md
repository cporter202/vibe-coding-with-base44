## How to study effectively

1. **Do the exercise.** Reading creates familiarity; building creates skill.
2. **Keep version one small.** Complete one user journey before expanding.
3. **Save evidence.** Write down the exact test that proves a feature works.
4. **Revert early.** Do not pile repair prompts onto a direction you already dislike.
5. **Review permissions manually.** Never trust a polished summary for sensitive access rules.
6. **Ship to a few people.** Observe real confusion before adding more features.
