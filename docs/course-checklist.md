# Course progress checklist

Copy this file into your own notes or GitHub issue and check each item as you complete it.

Quick tools: [one-page reference](quick-reference.md) ·
[starter kits](../starter-kits/README.md) · [glossary](glossary.md)

## Plan

- [ ] I can name one primary user
- [ ] I can state their main job in one sentence
- [ ] I chose three version-one features
- [ ] I wrote a not-now list
- [ ] My plan includes pages, tables, permissions, and acceptance criteria

## Build

- [ ] The primary happy path works from start to finish
- [ ] Required fields validate clearly
- [ ] Loading, empty, success, and error states exist
- [ ] Double-clicking does not create duplicate records
- [ ] The mobile layout is usable at 360px width

## Secure

- [ ] App visibility is intentional
- [ ] Login requirements match the product
- [ ] I reviewed Create, Read, Update, and Delete rules for every table
- [ ] User A cannot see User B's private records
- [ ] Public visitors cannot read private form submissions
- [ ] API keys are stored as Secrets, not frontend code
- [ ] The Base44 security scan passes

## Test

- [ ] Happy path passes
- [ ] Invalid input path passes
- [ ] Failed request and retry path pass
- [ ] Visitor, regular user, and admin roles were tested
- [ ] Keyboard navigation and visible focus were checked
- [ ] A regression test exists for each important bug fixed

## Launch

- [ ] Test/demo data contains no real sensitive information
- [ ] Privacy and support information are appropriate
- [ ] The live URL was tested in a private browser window
- [ ] The main flow was tested on a real phone
- [ ] Important data has an export or recovery plan
- [ ] A small beta group completed the flow without coaching

## Reflect

- [ ] I recorded where users hesitated
- [ ] I ranked improvements by user impact
- [ ] I avoided adding features that do not improve the main job
- [ ] I know the one metric that signals useful completion
- [ ] I recorded one lesson that would help another beginner

## Share

- [ ] I removed personal data, secrets, admin URLs, and confidential screenshots
- [ ] I can describe the user, problem, and outcome in one sentence
- [ ] I shared the result in the [project showcase](https://github.com/cporter202/vibe-coding-with-base44/issues/new?template=showcase.yml), if appropriate
