# Security policy

This repository contains educational documentation, not the Base44 platform or a deployed application.

## Reporting a guide security issue

If an example in this guide could encourage secret exposure, unsafe permissions, or another dangerous pattern, open a documentation issue without including real credentials or private data.

## Reporting a Base44 vulnerability

Do not report suspected Base44 platform vulnerabilities in this repository. Follow Base44's official security and support process from its [security overview](https://docs.base44.com/Setting-up-your-app/security-overview) or [contact support](https://docs.base44.com/Community-and-support/Contacting-support).

## Never include in an issue

- API keys, access tokens, or passwords
- Private customer or user records
- Payment details
- Session data
- Unredacted logs containing personal information
